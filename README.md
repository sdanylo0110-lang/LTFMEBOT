# LTFMEBOT — Life Tracker For Me

Telegram Mini App: личный трекер (привычки, вода, питание, тренировки, траты,
заметки, задачи) + заготовка ИИ-помощника. MVP, без геймификации (нет стриков/бейджей).

## Структура
- `index.html` — разметка всех экранов + нижняя навигация
- `css/style.css` — дизайн-система (тёмная, матовая, без неонового свечения)
- `js/storage.js` — слой данных поверх localStorage. Все функции изолированы
  так, чтобы позже заменить на реальный бэкенд/бот-API без переписывания app.js
- `js/charts.js` — лёгкие canvas-графики без внешних зависимостей
- `js/app.js` — роутинг между экранами, рендер, обработчики

## Экраны
1. **Сегодня** — кольцо прогресса, привычки/задачи, вода, калории (быстрый доступ)
2. **Обзор** — bento-сетка виджетов: питание, тренировка, траты, задачи, заметки, встречи
3. **История** — календарь-хитмап по дням + детали дня
4. **Аналитика** — графики за 14 дней: привычки/калории/траты
5. **Помощник (ИИ)** — интерфейс чата; бэкенд ещё не подключён

## Статус
MVP-скелет фронтенда. Данные хранятся локально в браузере (localStorage).
Бэкенд/бот-часть — следующий этап.

## Деплой
Статический сайт — можно захостить на GitHub Pages (Settings → Pages → branch `main`),
затем указать URL в @BotFather как Web App для бота.

# LTFMEBOT — Life Tracker For Me

Telegram Mini App: личный трекер (привычки, вода, питание, тренировки, финансы,
заметки, задачи) + заготовка ИИ-помощника. Без геймификации (нет стриков/бейджей).

## Структура
- `index.html` — разметка всех экранов
- `css/style.css` — дизайн-система (тёмная, матовая, без неонового свечения)
- `js/storage.js` — слой данных поверх localStorage, изолирован от UI
- `js/charts.js` — лёгкие canvas-графики без внешних зависимостей
- `js/app.js` — роутинг, рендер, обработчики, конвертация валют

## Экраны
1. **Сегодня** — кольцо прогресса, привычки, вода (квадраты-стаканы), калории
2. **Обзор** — bento-сетка: питание, тренировка, финансы, задачи, заметки, встречи
3. **Задачи** — полноценный список: активные / выполненные
4. **Заметки** — папки-вкладки, создание/редактирование/удаление
5. **Финансы** — баланс, доход/расход, распределение капитала (свои категории),
   переключение валют RUB/USD/EUR/UAH с live-конвертацией, советы (заглушка)
6. **Тренировки** — минуты, план на неделю, рост/вес, ИИ-советы (заглушка)
7. **Питание** — цель по калориям, дневник питания, выбор блюд по категориям
   с примерными калориями, желательные/нежелательные продукты, рост/вес, план,
   фото еды (открывает камеру, распознавание — заглушка)
8. **История** — календарь-хитмап + детали дня
9. **Аналитика** — графики за 14 дней
10. **Помощник (ИИ)** — интерфейс чата, бэкенд не подключён

## Валюты
Суммы хранятся внутри в RUB. Курс подтягивается на устройстве пользователя
(в браузере Telegram) с бесплатного публичного API без ключа
(`@fawazahmed0/currency-api` через jsDelivr, с резервным `open.er-api.com`),
кэшируется на 12 часов в localStorage.

## Статус
MVP-скелет фронтенда. Данные — в localStorage на устройстве. Бэкенд/ИИ — следующий этап.
